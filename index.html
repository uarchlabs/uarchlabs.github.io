// quick start

~/pacinoubuntu 22.04 
$ git clone --recurse-submodules https://github.com/uarchlabs/pacino
$ cd pacino && . tools/setup.sh
$ tools/build_tools.sh        # about 30 minutes, mostly unattended
$ make -C examples/fe_demo view S=fd09_tage
$ ./tools/regress.sh
  • build_tools.sh asks where to install the cross compiler
  • build_tools.sh stops if any system components are needed
  • the demo make builds and launches a Surfer window
  • the regression tests whether the development tools are ready, about 10 minutes
  • README.md
